# Movie Library App 🎬

A Flutter application that displays a collection of movies in List View and Grid View.

## Features

- Display movie cards with posters, titles, genres, release years, and ratings.
- Search movies by title or genre.
- Switch between List View and Grid View.
- Display a message when no movies match the search.
- Interactive discount feature shared across all movie cards.
- Local movie poster assets.

## Technologies Used

- Flutter
- Dart
- Material Design

## How to Run

1. Install Flutter.
2. Clone this repository.
3. Run `flutter pub get`.
4. Run `flutter run`.
